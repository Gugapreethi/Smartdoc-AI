# SmartDoc AI Suite

SmartDoc AI is an intelligent document analysis platform
built using Python, LangChain and Groq AI.

## Technologies Used
- Python
- LangChain
- Groq AI (LLaMA3)
- HuggingFace Embeddings
- FAISS Vector Store

##  Module 1 - Document QA Bot

AI Email Generator is a simple web application built 
using Python, LangChain and Groq AI. This project helps 
users ask questions from any PDF document automatically 
using Artificial Intelligence.
##  Features
- AI-powered PDF Question Answering
- Ask any question from PDF
- AI gives instant answers
- Simple and interactive
- Fast response using Groq AI
- Beginner-friendly structure
