# Day 8 Learning – SmartDoc AI Suite

Today I worked on Module 2 of SmartDoc AI, 
a Web Summarizer using Python, LangChain, and Groq AI.

## Technologies Used
- Python
- LangChain
- Groq AI (LLaMA3)
- BeautifulSoup4
- Requests
- Streamlit

## Features
- AI-powered Web Page Summarization
- Give any URL and get instant summary
- Multiple summary styles
- Bullet Points, Paragraph, Key Points
- Fast response using Groq AI
- Simple and interactive interface

## Project Module
### Module 2 – Web Summarizer
- Enter any website URL
- AI reads the webpage content
- Gives clear and concise summary
- Choose summary style

## Learning Outcome
I learned how to build a web scraping and 
summarization application using LangChain, 
BeautifulSoup4 for web scraping, and Groq AI 
for intelligent summarization of web content.
