# SmartDoc AI Suite

SmartDoc AI is an intelligent document analysis platform
built using Python, LangChain and Groq AI.

## Technologies Used
- Python
- LangChain
- Groq AI (LLaMA3)
- Streamlit
- LangChain Memory
- ChatPromptTemplate

## Module 3 - Chatbot with Memory

Chatbot with Memory is a simple web application built
using Python, LangChain and Groq AI. This project helps
users have multi-turn conversations where the AI
remembers previous messages and gives relevant
responses automatically using Artificial Intelligence.

## Features
- AI-powered Multi-turn Conversation
- Remembers Previous Messages
- Chat History Management
- Real-time AI Response
- Clear Chat Option
- Fast Response using Groq AI
- Beginner-friendly Structure

## Project Modules

### Module 3 - Chatbot with Memory
- Type any message in chat input
- AI remembers previous conversation
- Gives relevant responses based on history
- Clear chat option available

## Installation
pip install -r requirements.txt

## Run
cd module3_chatbot
streamlit run streamlit_app.py
